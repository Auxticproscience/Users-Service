# 📦 Users-Service

Servicio de gestión de usuarios para la intranet, parte del ecosistema de microservicios.  
Registra información de usuarios y sus cumpleaños, utilizando PostgreSQL como base de datos y Eureka para descubrimiento de servicios.

---

## 🛠️ Tecnologías

- Java 21
- Spring Boot 3.5.6
- Spring Data JPA
- PostgreSQL
- Eureka Client
- Lombok
- SpringDoc OpenAPI (Swagger)
